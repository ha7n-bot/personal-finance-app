# مالي لأندرويد 5.0 — نسخة تجريبية

- تُثبت باسم «مالي التجريبي» وبحزمة `com.ha7n.mali.preview` بجانب النسخة القديمة دون استبدالها.

- البريد وكلمة المرور يعملان داخل التطبيق.
- تسجيل Google يفتح في متصفح النظام ثم يعود برمز عشوائي صالح لخمس دقائق ويُستخدم مرة واحدة.
- النسخ الاحتياطي لتخزين التطبيق معطل لأن البيانات مالية.
- حزمة GitHub Actions للاختبار؛ إصدار المتجر يحتاج مفتاح توقيع Release دائمًا.

البناء: `gradle --no-daemon :app:assembleDebug`

ملف التجربة الناتج: `Mali-Android-v5-Preview.apk`.
