# مالي لأندرويد 6.0

- الإصدار الفعلي باسم «مالي» وبحزمة `com.ha7n.mali`؛ ليس تطبيقًا تجريبيًا منفصلًا.
- يمكنه تحديث أي إصدار سابق يحمل الحزمة نفسها وموقّعًا بمفتاح GitHub Actions المستقر.
- تسجيل Google يفتح في متصفح النظام ثم يعود إلى التطبيق برمز عشوائي صالح لخمس دقائق ويُستخدم مرة واحدة.
- البريد وكلمة المرور متاحان كخيار بديل، والبيانات المالية محفوظة في حساب المستخدم السحابي.
- النسخ الاحتياطي المحلي لتخزين التطبيق معطل لأن البيانات مالية.
- كل Pull Request يغيّر Android يبني APK فعليًا للتأكد من قابلية التثبيت قبل الدمج.

البناء: `gradle --no-daemon :app:assembleRelease`

الملف الناتج: `Mali-Android-v6.apk`.

ملاحظة: حزمة GitHub المباشرة موقعة بالمفتاح الثابت الحالي. النشر عبر Google Play يتطلب مفتاح إصدار محميًا وسياسة نشر للمتجر.
