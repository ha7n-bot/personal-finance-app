# مالي — تطبيق إدارة مالية شخصية

تطبيق عربي RTL للجوال والويب بالريال السعودي. يحتوي المشروع على تجربة حساب سحابية للويب وتجربة محلية أولًا مصممة لتطبيق Android بدون تسجيل دخول إجباري.

## Android 7 — Local-first

- تطبيق Android يفتح تجربة مالي المحلية مباشرة بدون إجبار المستخدم على إنشاء حساب أو تسجيل الدخول.
- الحسابات والعمليات والميزانيات والالتزامات تحفظ فورًا على الجهاز.
- يحتفظ التطبيق بنسخة ثانية من الحالة المالية داخل تخزين Android الخاص بالتطبيق بدل الاعتماد على WebView `localStorage` وحده.
- Android Auto Backup ونقل الجهاز مفعّلان فقط لبيانات مالي المحلية وتفضيلات التذكير، ولا يتم نسخ Cookies أو جلسات تسجيل الدخول أو ملفات WebView كاملة.
- عند توفر نسخة Android احتياطية وعدم وجود بيانات محلية صالحة، يستعيد التطبيق الحالة المالية تلقائيًا.
- بقاء البيانات بعد حذف التطبيق ثم إعادة تثبيته يعتمد على كون النسخ الاحتياطي للنظام مفعّلًا على جهاز المستخدم؛ لا يمكن لأي تطبيق محلي ضمان الاستعادة بعد الحذف عندما يعطّل المستخدم نسخ Android الاحتياطية.
- التذكيرات تعمل عبر Android AlarmManager ويمكن استمرارها بعد إعادة تشغيل الجهاز.
- WebView يمنع mixed content والوصول المباشر إلى الملفات المحلية، ويقصر التصفح الداخلي على نطاق مالي.

## تطبيق الويب والحساب السحابي

- `/` يفتح تسجيل الدخول أو لوحة المستخدم السحابية.
- `/demo` هو تطبيق مالي المحلي الذي يبدأ من صفر ويحفظ على الجهاز، وهو المسار المستخدم في Android 7.
- المسار السحابي يدعم Google أو البريد وكلمة المرور ويحفظ بيانات كل مستخدم في PostgreSQL بواسطة `userId`.
- توجد أداة استيراد للبيانات المحلية إلى الحساب السحابي لمن يختار استخدام نسخة الويب المسجلة، لكنها ليست جزءًا من تجربة Android المحلية الأساسية.

## الوظائف الأساسية

- واجهة عربية RTL واضحة ومتجاوبة وخط Noto Sans Arabic مضمّن.
- حسابات مالية متعددة: بنكي، نقدي، ادخار، محفظة واستثمار.
- دخل ومصروف مع تصنيفات وحساب مصدر/وجهة وتاريخ وملاحظات.
- عملية مرة واحدة أو مصروف شهري مستمر.
- ميزانيات شهرية والتزامات ومتابعة السداد.
- تقارير لفترات يومية وأسبوعية وشهرية ومتعددة الأشهر وسنوية.
- مكتبة تصنيفات قابلة للتخصيص والإخفاء.
- إعدادات وصول للخط والوزن والتباين وتقليل الحركة على مستوى التطبيق.
- PWA مع shell للوضع دون اتصال ومسار محلي آمن كـ fallback.
- تنبيهات Android يومية أو أسبوعية أو كل أسبوعين أو شهرية.
- النسخة السحابية تتضمن كذلك الأقساط المحددة والديون والأهداف وصندوق الطوارئ والاستثمارات ووظائف أوسع.

## الإعداد للويب

1. انسخ `.env.example` إلى `.env`.
2. حدّث `DATABASE_URL` و`AUTH_SECRET` و`MOBILE_API_SECRET` عند استخدام الوظائف السحابية.
3. شغّل `pnpm install`.
4. لأول قاعدة بيانات جديدة شغّل `pnpm prisma generate` ثم `pnpm prisma db push`.
5. شغّل `pnpm dev`.

في الاستضافة يشغّل `pnpm build` ترحيلات Prisma الآمنة قبل بناء Next.js، ويمكن تشغيلها منفصلة عبر `pnpm db:migrate`.

## Google OAuth للنسخة السحابية

أضف عناوين العودة التالية في Google Cloud عند تفعيل Google للويب:

- `http://localhost:3000/api/auth/callback/google`
- `https://mali-finance-app-zord2.vercel.app/api/auth/callback/google`

ثم أضف `AUTH_GOOGLE_ID` و`AUTH_GOOGLE_SECRET` إلى متغيرات بيئة الاستضافة. يقبل التطبيق أيضًا الاسمين `GOOGLE_CLIENT_ID` و`GOOGLE_CLIENT_SECRET` للتوافق مع إعدادات استضافة قديمة. لا تحفظ الأسرار في GitHub.

## الفحوصات

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
```

بناء Android يتم أيضًا عبر GitHub Actions في بيئة نظيفة، وينتج `Mali-Android-v7.apk` للإصدار 7.0.
