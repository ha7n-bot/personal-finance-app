# مالي — تطبيق إدارة مالية شخصية

تطبيق عربي RTL للجوال والويب بالريال السعودي. الإصدار 6 يجعل Google خيار الدخول الأساسي، ويوضح الحفظ السحابي، ويضيف بداية موجهة وخطًا عربيًا مضمّنًا وإعدادات لحجمه وسُمكه وتباينه، ويحسّن لوحة البيانات وتجربة Android.

## الحفظ والمزامنة

- `/` يفتح تسجيل الدخول أو لوحة المستخدم.
- `/demo` نسخة محلية تبدأ من صفر وتحفظ على الجهاز.
- زر **حفظ ومزامنة** ينقل الحسابات والعمليات والميزانيات والالتزامات إلى PostgreSQL بعد التسجيل.
- بعد الاستيراد يظهر الحساب نفسه على الجوال والويب.

## الوظائف الأساسية

- Google بشكل بارز أو البريد وكلمة المرور كخيار بديل.
- بيانات كل مستخدم معزولة في PostgreSQL بواسطة `userId` وتعود عند تسجيل الدخول بالحساب نفسه.
- دليل بداية واضح من الحساب الأول إلى أول دخل ومصروف.
- حجم خط قابل للتعديل، وسُمك أوضح، وتباين أعلى وتقليل للحركة.
- حساب رئيسي تلقائي لمنع قائمة الحساب الفارغة.
- دخل ومصروف مع تحقق من ملكية الحساب والتصنيف.
- التاريخ هو اليوم تلقائيًا ويمكن تغييره.
- المصروف أو الدخل مرة واحدة، أو شهري مستمر حتى يوقفه المستخدم.
- خطة أقساط محددة بإجمالي وعدد أشهر، مع حساب القسط والمتبقي والتقدم تلقائيًا.
- ميزانيات، دفعات متكررة، ديون، أهداف، صندوق طوارئ، استثمارات وتقارير متعددة الفترات.
- واجهة عربية واضحة ومتجاوبة، PWA وتطبيق Android.

## الإعداد

1. انسخ `.env.example` إلى `.env`.
2. حدّث `DATABASE_URL` و`AUTH_SECRET` و`MOBILE_API_SECRET`.
3. شغّل `pnpm install`.
4. لأول قاعدة بيانات جديدة شغّل `pnpm prisma generate` ثم `pnpm prisma db push`.
5. شغّل `pnpm dev`.

في الاستضافة يشغّل `pnpm build` ترحيلات Prisma الآمنة قبل بناء Next.js، ويمكن تشغيلها منفصلة عبر `pnpm db:migrate`.

## Google OAuth

أضف عناوين العودة التالية في Google Cloud:

- `http://localhost:3000/api/auth/callback/google`
- `https://personal-finance-app-rose-psi.vercel.app/api/auth/callback/google`

ثم أضف `AUTH_GOOGLE_ID` و`AUTH_GOOGLE_SECRET` إلى متغيرات بيئة الاستضافة. يقبل التطبيق أيضًا الاسمين `GOOGLE_CLIENT_ID` و`GOOGLE_CLIENT_SECRET` للتوافق مع إعدادات استضافة قديمة. لا تحفظ الأسرار في GitHub.

## Android

المصدر داخل `android-app`. تسجيل Google وربط حساب بريد موجود يفتحان في متصفح النظام عبر رموز أحادية الاستخدام صالحة لخمس دقائق، ثم يعودان إلى التطبيق. لا يربط مالي حسابين بالبريد نفسه تلقائيًا دون إثبات جلسة المستخدم الحالية. تنشئ GitHub Actions حزمة الإصدار الفعلي `Mali-Android-v6.apk`.

قبل الإطلاق العام النهائي يوصى بإضافة تحديد معدل محاولات الدخول، واستعادة كلمة المرور، ونسخ احتياطية دورية، واختبارات E2E.
