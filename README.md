# مالي — تطبيق إدارة مالية شخصية

تطبيق عربي RTL للجوال والويب بالريال السعودي. الإصدار 4 يوحّد تسجيل الدخول والبيانات، ويضيف Google إلى جانب البريد وكلمة المرور، ويحسّن الحسابات والعمليات المتكررة والتقارير وتجربة Android.

## الحفظ والمزامنة

- `/` يفتح تسجيل الدخول أو لوحة المستخدم.
- `/demo` نسخة محلية تبدأ من صفر وتحفظ على الجهاز.
- زر **حفظ ومزامنة** ينقل الحسابات والعمليات والميزانيات والالتزامات إلى PostgreSQL بعد التسجيل.
- بعد الاستيراد يظهر الحساب نفسه على الجوال والويب.

## الوظائف الأساسية

- Google أو البريد وكلمة المرور.
- حساب رئيسي تلقائي لمنع قائمة الحساب الفارغة.
- دخل ومصروف مع تحقق من ملكية الحساب والتصنيف.
- التاريخ هو اليوم تلقائيًا ويمكن تغييره.
- العملية مرة واحدة أو متكررة شهريًا.
- ميزانيات، دفعات متكررة، ديون، أهداف، صندوق طوارئ، استثمارات وتقارير متعددة الفترات.
- واجهة عربية واضحة ومتجاوبة، PWA وتطبيق Android.

## الإعداد

1. انسخ `.env.example` إلى `.env`.
2. حدّث `DATABASE_URL` و`AUTH_SECRET` و`MOBILE_API_SECRET`.
3. شغّل `pnpm install`.
4. شغّل `pnpm prisma generate` ثم `pnpm prisma db push`.
5. شغّل `pnpm dev`.

## Google OAuth

أضف عناوين العودة التالية في Google Cloud:

- `http://localhost:3000/api/auth/callback/google`
- `https://personal-finance-app-rose-psi.vercel.app/api/auth/callback/google`

ثم أضف `AUTH_GOOGLE_ID` و`AUTH_GOOGLE_SECRET` إلى متغيرات بيئة الاستضافة. لا تحفظ الأسرار في GitHub.

## الفحوصات


## Android

المصدر داخل `android-app`. تسجيل Google يفتح في متصفح النظام ثم يعود إلى التطبيق برمز أحادي الاستخدام صالح لخمس دقائق. تنشئ GitHub Actions حزمة `Mali-Android-v4.apk` للاختبار.

قبل الإطلاق العام يوصى بإضافة ترحيلات Prisma رسمية، تحديد معدل محاولات الدخول، استعادة كلمة المرور، نسخ احتياطية واختبارات E2E.
