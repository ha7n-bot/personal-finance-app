# حارس الوقت — Focus Guard

تطبيق أندرويد شخصي لفرض حد استخدام يومي على التطبيقات.

## ما يفعله الإصدار 1.0
- تحديد حد يومي بالدقائق/الساعات لكل تطبيق.
- احتساب الاستخدام من بداية اليوم عبر Usage Access.
- خدمة Accessibility تراقب التطبيق المفتوح.
- عند انتهاء الحد يظهر حاجب كامل للشاشة ويمنع الاستمرار في التطبيق.
- إعادة السماح تلقائيًا بعد منتصف الليل.
- قفل تعديلات اليوم: لا يمكن زيادة الحدود أو حذفها حتى اليوم التالي، مع السماح بتقليل الحدود.
- واجهة عربية RTL.

## التشغيل
1. افتح التطبيق.
2. فعّل إذن "وقت الاستخدام".
3. فعّل خدمة "حارس الوقت" من إمكانية الوصول.
4. أضف التطبيقات وحدد لكل واحد حدًا يوميًا.
5. اختياريًا فعّل "قفل زيادة الحدود والحذف حتى الغد" بعد ضبط الحدود.

## ملاحظة تقنية
هذا تطبيق عادي بدون Root وبدون صلاحية Device Owner. لذلك لا يستطيع إيقاف تشغيل هاتف Samsung فعليًا أو منع إزالة التطبيق/مسح بياناته من إعدادات النظام. المنع داخل التطبيقات يعتمد على Accessibility Service وهو أقوى مسار عملي لتطبيق شخصي بدون Root.
